# Privacy Policy for My Health

My Health is a local-first personal health notebook. It does not collect or transmit personal information, health information, browsing history, website content, location data, or advertising identifiers. The extension includes no advertising, analytics, tracking, cloud synchronization, or remote data storage.

## Data Stored
The extension stores user-entered information, including profile details, health records, notes, preferences, and uploaded attachments. It also stores interface settings such as language, calendar, and measurement units. This information is kept locally in the extension's browser storage on the current device and is not sent to the developer or shared with third parties.

## Backup and Restore
Users can export locally stored information and attachments to a JSON backup file and restore it later. A backup may contain sensitive health information in readable form. The user is responsible for securely storing, transferring, and deleting backup files.

## Permissions
- `storage` supports keeping extension data and preferences locally between sessions.
- `alarms` supports local medication-reminder events.
- `notifications` displays medication reminders on the device.
These permissions are not used to read visited websites, browsing history, device files, or account information. The extension requests no host permissions and does not send reminder or health data over the internet.

## Data Control and Retention
Users can delete all locally stored health data from within the extension. Removing the extension or clearing its browser data may also permanently delete the data. Users should back up their data before doing so if they want to keep their records.

## External Links
GitHub and donation links open external websites only when the user selects them. Once an external site is opened, that site's privacy policy applies.

## Medical Disclaimer
My Health is intended only for personal record-keeping. It does not provide medical diagnosis, treatment, prescriptions, emergency assistance, or professional medical advice. Users should contact emergency services or a qualified healthcare professional when appropriate.

## Changes to This Policy
This policy may be updated when the extension's features or data practices change. We will document material changes in the project repository.

Questions or concerns can be submitted through the [My Health GitHub repository](https://github.com/amirshnll/my-health-browser-extention/issues).
